01

USB로 연결하기

기기의 개발자 옵션에서 USB 디버깅을 켜고 이 PC에 연결하세요. 기기에 표시되는 RSA 키 인증 요청을 허용하면 온라인 상태로 표시됩니다.

adb devices -l
02

무선으로 연결하기

Android 11 이상에서는 PC와 같은 Wi-Fi에 연결한 뒤 개발자 옵션의 무선 디버깅을 켜세요. ‘페어링 코드로 기기 페어링’을 열고 이 사이트의 무선 검색에서 페어링 버튼을 누르세요.

무선 검색 → 페어링 → 숫자 6자리 입력

페어링이 끝나면 연결 서비스의 ADB 연결 버튼을 누르세요. 이미 자동 연결된 기기는 연결 해제 버튼이 표시됩니다.

연결 서비스 → ADB 연결
03

상태 확인하기

인증 대기라면 기기 화면에서 디버깅을 허용하세요. 오프라인이라면 케이블이나 Wi-Fi 연결을 확인한 뒤 다시 연결하세요.

무선 검색의 연결 해제 버튼은 해당 기기의 무선 연결을 모두 해제합니다. USB 연결과 다른 기기 연결은 유지됩니다.

5초 간격 · PC에 최근 7일 보관 · 탭을 닫아도 수집 · 기록 기준 보기

이 PC에서 ADB Desk 서버가 켜져 있고 기기가 ADB에 연결되어 있는 동안 수집합니다. 새로고침·다른 탭·브라우저 종료와 무관하게 기록하며 서버를 다시 켜도 저장 기록은 유지합니다. 서버 종료·PC 절전·연결 해제·조회 실패 구간은 선을 이어 그리지 않습니다. 연결 감지는 약 5초 간격이며, 이 기능 추가 이전의 값은 수집할 수 없습니다.

CPU·RAM 그래프에 마우스를 올리면 당시 CPU·RAM 상위 5개 앱·프로세스를 확인합니다. 이 목록은 현재 실행 중인 목록이 아닌 저장된 시점의 1초 CPU 표본과 RSS 메모리입니다. 앱별 기록이 없는 이전 시점에는 안내를 표시합니다. CPU는 전체 코어의 비유휴 사용률(입출력 대기 제외), RAM은 전체 − 사용 가능(MemAvailable), 저장소는 /data 사용량입니다. 용량은 1 GB = 1,000,000,000바이트입니다. 긴 기간은 평균 선과 최소~최대 범위로 표시하며, CSV에는 선택한 기간의 원본 측정값을 저장합니다. 조회 불가 항목을 0으로 표시하지 않습니다.
